# Reference Library

This folder stores research notes and reusable agent templates for dot-studio.

- `project/` contains downloaded open-source projects used for study.
- `2d-pixel-editors.md`, `3d-voxel-editors.md`, `file-formats.md`, `scene-editors.md`, `license-review.md`, and `architecture-decisions.md` summarize what can be learned.
- `agent-template/` is a copyable starter pack for future repositories.

Reference code is not automatically reusable. Check license boundaries before copying implementation.
