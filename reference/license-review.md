# License Review

## Current Rule

Reference projects are study material. Do not copy source code unless the license is reviewed and compatible with dot-studio's intended distribution.

## Downloaded References

- Pixelorama: MIT. Code can be studied and may be reusable with attribution if needed.
- vengi: MIT. Code can be studied and may be reusable with attribution if needed.
- Goxel: GPL-family via `COPYING`. Use as architecture reference only unless dot-studio adopts compatible licensing.
- LibreSprite: GPL-family. Use as architecture reference only unless dot-studio adopts compatible licensing.
- Blockbench: license requires review before any reuse. Treat as architecture/UX reference only for now.

## Reuse Boundary

- Allowed: architectural patterns, UX concepts, naming inspiration, test scenarios.
- Needs review: copying code, assets, shaders, palettes, icons, exporter logic.
- Avoid by default: directly porting GPL implementation into this repository.
